# Market Pro — Official APK Releases

Public **signed-APK-only** distribution repository for Market Pro.

Only verified signed Android APKs, checksums, and release notes belong here. Never publish Kotlin/Android source code, private keys, keystore, passwords, Supabase service-role secrets, or business data.

**Migration is not yet active.** Existing Market Pro installations currently use the original source repository and Supabase update channel. Keep those links available until a signed dual-repository bridge APK passes Owner/Subscriber in-place update testing.

Each published APK must pass Android package-ID, signing-certificate, monotonically increasing versionCode, SHA-256 integrity and release QA checks.
